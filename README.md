# PARTEA Web Application

Frontend for **PARTEA** (Privacy-Aware Time-to-Event Analysis), a federated platform for cross-institutional survival analysis without sharing raw patient data.

## What this is

This is the web-based interface for setting up federated survival studies across multiple institutions: configuring cohorts, monitoring federated computation rounds, and visualizing results (Kaplan-Meier curves, Cox hazard ratios, federated survival SVMs).

For the coordination backend, see [federated-partea/server](https://github.com/federated-partea/server).

## Tech Stack

- Angular, TypeScript
